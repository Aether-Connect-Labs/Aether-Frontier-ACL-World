# Aether-Frontier-ACL-World
Bienvenido a la frontera digital de Aether Connect Labs. En este juego de estrategia y clics, eres un Arquitecto de Redes. Tu misión es fortalecer el ecosistema, recolectar energía y convertir tus logros en tokens ACL.  🚀

## 🚀 Despliegue en Vercel

Este proyecto está optimizado para desplegarse automáticamente en Vercel.

1.  Sube este repositorio a tu GitHub.
2.  Inicia sesión en [Vercel](https://vercel.com).
3.  Importa el repositorio.
4.  Vercel detectará automáticamente `index.html` y desplegará el juego.
